الرابط الجديد: **https://well-ads.pages.dev**. الموقع القديم: https://well-ads-dashboard.vercel.app (يبقى بدون لمس 7 أيام كاحتياط).

## الليلة (نص ساعة، تبدأ بموافقة لين)

1. **نسخة احتياطية:** في الريبو القديم شغّل `db-backup` وتأكد إنه نجح.
2. **وقف الكاتب القديم** (كاتب واحد بس على القاعدة):
   ```bash
   gh workflow disable refresh-and-deploy -R leen-saz/well-ads-dashboard
   ```
3. **أول سحب على الجديد:**
   ```bash
   gh workflow run refresh -R leen-saz/well-ads --ref main
   ```
   ينتظر لين ينجح: السحب، القرارات، الرفع لـ R2، وفحص الصحة.
4. **فحص:** دخول على الرابط الجديد، التحليلات، الكرييتف، الأقسام، لوحة القرارات، الربط. الأرقام تطابق آخر تحديث للقديم.
5. **الجدولة:** طلب دمج يضيف `cron: "7 * * * *"` لـ `refresh.yml` ويوقف نسخة الإنتاج من `pipeline.yml` (التصدير للقراءة بس يبقى للتجربة).
6. **قروك:** يرفع على الجديد بس.
7. **الموقع القديم:** طلب دمج في الريبو القديم يحوّل كل الصفحات للرابط الجديد (والنشر القديم واقف، فينشر يدوي مرة).
8. **مراقبة 30 دقيقة:** سجلات الـ Worker وأول تشغيل مجدول.
9. **الموظفين:** الرابط الجديد، وكل واحد يسجل دخول مرة (سر الجلسات جديد).

## الرجوع (خطوة وحدة)

```bash
gh workflow disable refresh -R leen-saz/well-ads && gh workflow enable refresh-and-deploy -R leen-saz/well-ads-dashboard
```

وبعدها إلغاء تحويل الموقع القديم (revert لطلب الدمج في الخطوة 7). فيرسل ما انحذف، فالرجوع فوري.
