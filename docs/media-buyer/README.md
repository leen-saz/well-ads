# الميديا باير (`buyer`)

إيجنت يقرأ أرقام الإعلانات في الداشبورد ويقارنها بقاعدة أفضل الممارسات لكل منصة وبقواعد الشركة، ويطلع **توصيات** مرتبة. **قراءة بس**: ما يغيّر أي حملة ولا ميزانية ولا إعلان، والمشتري الإعلامي ينفّذ يدوياً.

| الملف | وش فيه |
|---|---|
| `research.md` | المشاريع المفتوحة المصدر والمعايير اللي فحصناها، والرخصة والحكم على كل واحد |
| `sources.md` | مصادر الحقائق، كل حقيقة بروابطها ودرجة التحقق |
| `rules.md` | القواعد: متى تطلع، ليش، المخاطر، مقياس النجاح، وشرط حكم التسويق |
| `company-rules.md` | قواعد الشركة (أسماء حملات وحدود): آلية الحفظ في قاعدة البيانات وشكلها |
| `platforms/*.md` | أفضل الممارسات لكل منصة (ميتا، تيك توك، سناب، جوجل) وعبر المنصات |
| `learning-loop.md` | لوب التعلّم، وكيف يرجع تحسين الإيجنت كـ PR تطويري |

الكود: `src/modules/buyer/` (`playbook.ts` البيانات والعتبات، `buyer.ts` المحرّك، `rules.ts` فحص قواعد الشركة، `learn.ts` نتيجة التوصية، `routes.ts` الـ API). الصفحة `/buyer/` في «التحسين والقرارات».

## الحدود (صارمة)
- **قراءة بس** على حسابات الإعلانات: المحرّك يقرأ جدولي `ads` و`ad_metrics` في قاعدتنا، وما عنده اتصال بأي منصة. كل توصية معلّمة `readOnly: true`، والاختبار يتأكد إن الموديول ما فيه أي نداء لواجهات المنصات.
- **ما يكتب في `suggestions`**: ذاك الجدول ينفّذه المنفّذ بعد الموافقة، والميديا باير يقترح بس.
- **الريبو عام**: ما فيه أرقام أعمال ولا أسماء حملات ولا أسرار. حد الإيقاف وخطوات الميزانية وأسماء الحملات وحدودها تنحفظ في قاعدة البيانات (`control_settings.guardrails.buyer`) وليس هنا. الاختبارات ببيانات صناعية.
- **حكم التسويق أول**: كل توصية تمر على `pipeline/dash/00-judge.js`. التوسيع يطلع بس لو الحكم على الـ CPL «تمام»، والإيقاف بس لو «انتبه» أو أسوأ. اللي وقفه الحكم يظهر تحت «توصيات وقفها الحكم» مع السبب.
- **النصوص**: عربي بصيغة المذكر، وبدون أي ادعاء صحي (الاختبار يمرر كل نص على فاحص الامتثال). تيك توك يبقى على MCP: الإيجنت ما يستخدم مفاتيح مباشرة.

## إعدادات الشركة (في قاعدة البيانات)
`control_settings.guardrails` لكل منصة، مفتاح `buyer`: `{ "stop_cpl": رقم, "ladder": [درجات الميزانية اليومية], "rules": [...] }`، و`target_cpl` لهدف الـ CPL. بدونها يستخدم أهداف الحكم الافتراضية. شكل القواعد في `company-rules.md`، وتنحفظ من `POST /api/buyer/rules` (لين فقط).
