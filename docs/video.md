# الفيديو (دمج DaVinci، المرحلة 4)

موديول `video`: فيديو إعلاني من رابط منتج أو خدمة، أفاتار يتكلم، ولقطات قصيرة. **مقفل** لكل شركة لين تفتحه لين من الإعدادات ← الموديولات
(المايقريشن 032 تقفله مرة وحدة). ما ننسخ كود DaVinci ولا برومتاته (رخصة تجارية)؛ فكرة المحركين وخريطة القدرات والفحص قبل الإرسال فقط إلهام.

## القرارات (لين، 2026-11-04)
- المحرك: Higgsfield مع Seedance. الأفاتار والفيديو يشتغلون بمهارة (سجل مهارات)، مو أفاتار ثابت.
- الاعتماد: أنس (مراجع) ثم شكيب (معتمد). لين تعدّل وتعتمد دايم، ولو غاب أحدهم.
- سقف الصرف الشهري: ما نحط الحين. حقل للمالكة بس في ماويسترو ← الصرف (فاضي = بدون سقف)؛ التاب `video` يطلع فيه تلقائي.
- بدون مفاتيح المحرك: الصفحة تقول «ما اكتمل تجهيزه، بلّغ الإدارة» (والمالكة ترى أسماء الأسرار بس).

## الطبقات
| الملف | وظيفته |
|---|---|
| `engine.ts` | واجهة المحرك، خريطة القدرات، الفحص قبل أي طلب خارجي (رسالة عربية واضحة بدل رد 400 خام)، سجل مهارات الأفاتار |
| `higgsfield.ts` | محوّل Higgsfield (Seedance): إرسال، حالة، تصنيف الأخطاء (يعاد أو نهائي) |
| `engines.ts` | قائمة المحركات. محرك جديد = ملف وسطر |
| `jobs.ts` | دورة حياة الطلب (لقطة = طلب): بالانتظار ← يتولّد ← جاهزة أو ما تمت. إعادة محاولة بتأخير متزايد (حد أقصى 3)، فحص السقف قبل كل إرسال، تكلفة تنكتب مرة وحدة في `ai_usage`، والملف ينتسخ لتخزيننا |
| `routes.ts` | `/api/video/{engines,projects,jobs,file}` |

الطلب يتحرك لما الصفحة تسأل عن حالته (كل 5 ثواني طول ما فيه لقطة تنتظر). كل تغيير حالة PATCH مشروط بالحالة اللي شافها المنادي، فلو نادَوا اثنين بنفس الوقت يرسل واحد بس.

## الأسرار (Worker secrets، تضيفها لين بنفسها)
`HIGGSFIELD_API_KEY`, `HIGGSFIELD_API_SECRET`، واختياري `HIGGSFIELD_SEEDANCE_MODEL`. الأسماء في `docs/secrets/worker.env.example`.

## تنبيه للتحقق قبل أول تشغيل مدفوع
شكل الطلبات (`Authorization: Key <key>:<secret>`، المسار `/<model>/text-to-video` أو `/image-to-video`، حالة الطلب `/requests/<id>/status`)
مأخوذ من توثيق Higgsfield Cloud كما تنقله مصادر ثالثة؛ يتحقق منه المالك على المرجع الرسمي (docs.higgsfield.ai). والأسعار في
`src/lib/prices.ts` (`VIDEO_PRICES`) **تقديرية** وتبقى `verified: false` لين تتطابق مع فاتورة.

## الجداول (032)
`video_projects` (المشروع، الموجز، السكربت، حالة المراجعة والاعتماد)، `video_jobs` (اللقطات)، `video_settings` (المراجع والمعتمدون). كلها `company_id`، RLS مفعّل ومقفول عن anon و authenticated.
