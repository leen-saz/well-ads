**القاعدة:** الموقع الحالي (`leen-saz/well-ads-dashboard` على Vercel) يبقى شغّال وما يتلمس لين نهاية المرحلة 7. الريبو الجديد ينبني جنبه، ويثبت إنه يطابقه، وبعدين نحوّل.

## التركيبة (ADR-0001)
| الطبقة | الأداة |
|---|---|
| الصفحات | **Astro** (TypeScript) على Cloudflare Workers |
| الـ API والبوابة | **Hono** داخل نفس الـ Worker (`/api/*`) |
| القاعدة والدخول والخزنة | **Supabase** عن طريق **Hyperdrive** (ADR-0002) |
| الملفات (الأغلفة، `data.json`) | **R2** خاص، يوصله الـ Worker بعد التحقق من الدخول |
| سحب البيانات | **بايثون + PyAirbyte** في **GitHub Actions** (ADR-0003) |
| الاختبارات | **Vitest** + **Playwright** + `unittest` للبايثون |
| الـ CI | lint ← typecheck ← اختبارات ← build ← فحص migrations على Postgres مؤقت ← فحص أسرار واعتماديات |
