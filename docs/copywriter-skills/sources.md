## الرسائل والإيميل
- **[م20]** واتساب: تصنيفات القوالب (تسويقي، خدمي، توثيق)، ونافذة الـ24 ساعة، والموافقة المسبقة. https://developers.facebook.com/docs/whatsapp/pricing/ · سياسة الرسائل التجارية (الموافقة، والإيقاف، والتحويل لموظف): https://whatsappbusiness.com/policy/
