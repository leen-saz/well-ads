# لوب التعلّم لكل تاب + تاب الكوبي رايتر

**الحالة:** معتمدة · 2026-11-02 (لين وافقت على الترتيب واسم الريبو `leen-saz/playbook`. تحقق الهوية في Meta من لين قبل C2)
**من ملاحظات لين (2026-11-02):**
- لوب تعلّم لكل تاب، يرمي دروسه على التاب نفسه وعلى المايسترو، والمايسترو يراجع ويعرف لمين يسند المهام.
- البيست براكتس تنحفظ في GitHub، عشان تستفيد منها بقية المشاريع.
- **تاب كوبي رايتر:**
  - إعداد لكل مشروع، وفيه خانة لروابط حسابات المنافسين أو أسمائهم، يحللهم وياخذ نمطهم بالملّي
  - متناسق جداً مع العميل السعودي
  - لوب تعلّم يومي يدوّر على تحديثات وسكلز جديدة في الكوبي رايتنق السعودي

**قرار لين:** مجاني بالكامل. GitHub Actions + Workers AI المجاني، بدون بحث ويب مدفوع.

## 1. هيكل واحد لكل التابات
**الموجود اليوم:** جدول `lessons` (migration 004)، ويستخدمه لوب الإعلانات بس (`pipeline/modules/learn`)، بدون شركة وبدون تاب.

**الإضافة (migration جديد):**
- `lessons.company_id` و `lessons.module` (مفتاح التاب، مثل `ads` و `copy` و `social` و `design`).
- `lessons.status`: `new` ← `reviewed` (المايسترو شافه) ← `approved` (لين اعتمدته) ← `exported` (انحفظ في GitHub).
- `lessons.source`: من وين جا الدرس (أرقامنا، منافس، مصدر خارجي)، مع رابط الدليل في `evidence`.

**كل تاب يعرّف `learn(company)`:**
- حسابات ثابتة على بياناته، رخيصة وبدون LLM قدر الإمكان.
- ويطلع منها دروس بصيغة وحدة: الدرس، والدليل، والثقة.
- **أمثلة:**
  - **الإعلانات:** الموجود اليوم.
  - **السوشال:** أي وقت نشر يجيب تفاعل أعلى.
  - **التصميم:** أي مقاس وصيغة تكلفتها أقل.
  - **الرصد:** أي كلمات ترتفع.
  - **الكوبي رايتر:** أي افتتاحية أو طول نص يجيب ليد أرخص.

**وين يشتغل:**
- GitHub Actions يومي (مجاني).
- يكتب في `lessons` عن طريق الخزنة، مثل `refresh.yml`.
- الـ LLM (Workers AI) **بس** لتلخيص الدرس بالعربي، وفيه سقف يومي لكل شركة حتى ما نطلع من الحد المجاني.

## 2. وين تطلع الدروس
- **في التاب نفسه:** كرت "وش تعلّمت": آخر الدروس مع دليلها، وزر "اعتمد" أو "تجاهل" لصاحب صلاحية الموافقة.
- **في المايسترو:**
  - كل درس جديد يصير مهمة مراجعة في Paperclip، مسندة لإيجنت التاب.
  - المايسترو يقرر: يعتمده، أو يحوّله لمهمة تنفيذ لإيجنت ثاني (مثلاً درس من الرصد يروح لمهمة للكوبي رايتر).
  - **لو Paperclip مو متصل** (النفق واقف): الدروس تنتظر في `lessons` بحالة `new`، وتنرسل أول ما يرجع. ما يضيع شي.
- **في GitHub (البيست براكتس):**
  - أسبوعياً، Action يكتب الدروس **المعتمدة بس** في ريبو `leen-saz/playbook`، في `best-practices/<التاب>.md`.
  - **بدون أي بيانات عملاء أو أرقام شركة.** الدرس العام والدليل المختصر بس.
  - لين توافق على الـ PR قبل ما ينحفظ.

## 3. تاب الكوبي رايتر (`copy`)

### الإعداد (مرة لكل مشروع)
- الخدمة أو المنتج، والجمهور (مدينة، عمر، جنس)، والعرض، والدعوة للفعل.
- **صوت العلامة:** نبدأ من دليل الصوت الموجود في تاب الصوت (سعودي واضح، جمل قصيرة).
- **المنافسين:** خانة تقبل روابط حسابات (فيسبوك وانستقرام وتيك توك وX) أو أسماء.
- **كلمات ممنوعة:** قواعد وزارة الصحة من تاب الامتثال، والعميل يضيف عليها.

### تحليل المنافسين ("نمطهم بالملّي")
**المصادر المجانية:**
- **Meta Ad Library API:** نصوص إعلانات المنافس الشغّالة. مجاني، يحتاج تحقق هوية مرة وحدة من لين.
- **النص اللي يلصقه المستخدم:** منشورات أو إعلانات.
- **صفحات الموقع العامة.**

**الناتج: "بطاقة نمط" لكل منافس:**
- الافتتاحيات المتكررة، وطول النص، واللهجة (كلمات سعودية مثل "وش" و"ابي")
- الإيموجي، والدعوة للفعل، والعروض، وأوقات النشر
- كل بند معه أمثلة حرفية من مصدرها

**حسابات أكثر وأقل:**
- الحسابات (طول الجمل، وتكرار الكلمات، واللهجة) بكود ثابت.
- الـ LLM للوصف بس.

### كتابة النصوص
- **المدخلات:** الإعداد + بطاقات النمط اللي يختارها المستخدم + أفضل إعلاناتنا (من بيانات الإعلانات).
- **الناتج:** 3 إلى 5 نسخ لكل مقاس، وكل نسخة تمر على فاحص الامتثال (تنبيه بس) وفاحص اللهجة.
- **ممنوع:** نسخ نص منافس حرفياً. ناخذ النمط، مو الكلام.

### اللوب اليومي
1. **أرقامنا:** أي نصوص جابت ليد أرخص أمس ← درس.
2. **المنافسين:** إعلانات جديدة في Ad Library ← تحديث بطاقة النمط، والجديد يطلع كدرس.
3. **سكلز وتحديثات:**
   - يدوّر في GitHub API (مجاني) على ريبوهات سكلز للكوبي رايتنق العربي والسعودي، وتحديثات الريبوهات اللي نتابعها
   - الجديد يطلع **اقتراح للين**، وما ينثبت لحاله
4. **المايسترو:** كل اللي فوق يروح له للمراجعة.

## 4. حدود صريحة
- **ما فيه بحث ويب مفتوح مجاني.** المنافسين اللي ما عندهم إعلانات Meta، أو حساباتهم انستقرام وتيك توك بس، نحتاج نص ملصوق أو رابط صفحة عامة.
- **انستقرام وتيك توك** ما يعطون منشورات حسابات غيرك مجاناً عبر API رسمي، وما نسوي scraping.
- **جودة Workers AI بالعربي أقل من النماذج المدفوعة.** نعوّض بقواعد ثابتة للهجة، وبأمثلة حقيقية من بياناتنا.
- **المايسترو يحتاج Paperclip شغّال.** النفق الحالي يوقف لما ينام الجهاز، والحل الدائم هو المرحلة 9.
