# هيكل الإيجنتس المستهدف

نفس تقسيم القائمة الجانبية (`GROUPS` في `public/assets/sidebar.js`، ويقرؤه `src/modules/registry.ts` وصفحة المدير). الإيجنتس نفسهم يعيشون في Paperclip (`docs/paperclip.md`)، وهذا الملف هو الشكل اللي نبي نوصله. الكود ما يسوي شي في Paperclip لين يتربط.

ميثاق عمل جلسات الكود (النطاق، المهام الدائمة، المقاييس، الجولة الأسبوعية) في [`agents/README.md`](agents/README.md). هذا الملف يبقى للهيكل الإداري في Paperclip.

## القاعدة الثابتة
**ولا إيجنت يكتب على الحسابات الإعلانية** (ميتا، تيك توك، سناب، قوقل). كلهم يقرؤون، يقترحون، ويكتبون مسودات ومهام. أي تغيير فعلي (ميزانية، إيقاف، نشر) يمرّ بقرار في لوحة القرارات وموافقة من إنسان.

## الهيكل
ملاحظة: القائمة الجانبية فيها 6 أقسام كحد أقصى، فالحوكمة مدموجة مع النظام في قسم «النظام والحوكمة». قائد الحوكمة وقائد النظام يبقون قائدين منفصلين في Paperclip، وصفحة المدير تعرض إيجنتس القسمين تحت العنوان نفسه.

```
المدير (CEO)
├─ قائد القياس والتحليل
│   ├─ محلل الأداء        ← ملخص الأداء والمواد الإعلانية
│   └─ الراصد             ← الرصد
├─ قائد الإنتاج
│   ├─ المصمم             ← التصميم
│   ├─ الكوبي رايتر       ← المحتوى و SEO (والكوبي رايتر)
│   ├─ الصوتي             ← الصوت والفويس أوفر
│   ├─ المفرّغ            ← التفريغ
│   └─ واصف الصور         ← وصف الصور
├─ قائد النشر والتوزيع
│   ├─ مدير السوشال       ← السوشال
│   └─ مصمم الرحلات       ← الرحلات والرسائل
├─ قائد التحسين والقرارات
│   ├─ المتتبع (Debugger) ← التتبع
│   └─ الناقد / المدقق    ← لوحة القرارات (يراجع قبل ما يوصل قرار للإنسان)
├─ قائد الحوكمة
│   └─ مراقب الامتثال     ← الامتثال والسجل
└─ قائد النظام
    ├─ أمين المعرفة       ← المعرفة
    └─ مشرف الربط         ← الربط
```
«الرئيسية» (احلم) ما لها قائد: هي واجهة المدير نفسه.

## الإيجنتس: مهمة كل واحد وما يقرأه
| الإيجنت | مهمته (سطر واحد) | يقرأ | يكتب |
|---|---|---|---|
| المدير (CEO) | يوزّع المهام على القادة ويلخّص للمالكة | ملخصات القادة، الوارد | مهام وتعليقات |
| قائد القياس والتحليل | يتابع الأرقام ويرفع ما يستحق انتباه | ملخص الأداء، المواد، الرصد | مهام وملاحظات |
| محلل الأداء | يشرح وش تغيّر في الصرف والنتائج ولماذا | أرقام الحملات والمواد (قراءة فقط) | ملاحظات |
| الراصد | يلخص كلام الناس عن Well والمنافسين | نتائج الرصد | ملخصات |
| قائد الإنتاج | يرتب طلبات الإنتاج حسب الأولوية | مهام الإنتاج | مهام |
| المصمم | يقترح تصاميم من الموجز | الموجز، مكتبة المواد | مسودات تصميم |
| الكوبي رايتر | يكتب نصوص إعلانية ومقالات SEO | الموجز، المعرفة | مسودات نصوص |
| الصوتي | يجهّز نص وتعليق صوتي | النص المعتمد | مسودات صوت |
| المفرّغ | يفرّغ الصوت والفيديو لنص | الملفات المرفوعة | نص التفريغ |
| واصف الصور | يوصف الصور ويكتب النص البديل | الصور المرفوعة | أوصاف |
| قائد النشر والتوزيع | يرتب جدول النشر والرحلات | جدول السوشال، الرحلات | مهام |
| مدير السوشال | يجهّز المنشورات والمواعيد | المحتوى المعتمد، الجدول | مسودات منشورات (النشر بموافقة) |
| مصمم الرحلات | يرسم رحلات الرسائل | بيانات الرحلات | مسودات رحلات |
| قائد التحسين والقرارات | يحوّل التوصيات لقرارات قابلة للتنفيذ | القرارات، تقارير القياس | مهام |
| المتتبع (Debugger) | يتأكد إن البكسل والأحداث تنقاس صح | سجلات التتبع | تقرير مشاكل |
| الناقد / المدقق | يراجع التوصيات ويرفض اللي أرقامه ضعيفة | القرارات المقترحة والأرقام | تعليق قبول أو رفض |
| قائد الحوكمة | يتأكد إن كل شي يمرّ بالمراجعة | الامتثال، السجل | مهام |
| مراقب الامتثال | يفحص المحتوى على ضوابط وزارة الصحة | المحتوى والإعلانات (قراءة) | تقرير مخالفات |
| قائد النظام | يتابع صحة الربط والمعرفة | حالة الربط | مهام |
| أمين المعرفة | يحدّث المعرفة بالمعتمد فقط | المعرفة والدروس | اقتراحات تحديث |
| مشرف الربط | ينبّه لما ينقطع ربط منصة | حالة الربط (بدون المفاتيح) | تنبيهات |

لا أحد منهم يقرأ مفاتيح الربط أو الأسرار.

## وش تسوي لين نربط Paperclip (يدوياً، لين)
1. في Paperclip أنشئ إيجنت لكل صف في الجدول، وخلّ `reportsTo` للقائد، والقادة تحت المدير.
2. أسند كل إيجنت لمشروع تابه `tab · <مفتاح التاب>` (مثل `tab · social`)، والقادة يتابعون مشاريع تابات مجموعتهم.
3. اختر الموديل لكل إيجنت (`docs/paperclip.md`) وحدّد ميزانية شهرية.
4. لا تعطي أي إيجنت مفاتيح الحسابات الإعلانية.

## وش يسوّيه PR لاحق
- زر للمالكة في المدير يقارن الإيجنتس الموجودين بهذا الجدول ويقترح الإنشاء والنقل (يحتاج اتصال Paperclip، خارج هذا التغيير).
- إسناد المهمة الجديدة تلقائياً لإيجنت التاب من قائد مجموعته.

## وش تغيّر في الكود الحين
صفحة المدير تعرض قائمة المهام والإيجنتس مقسّمة بنفس مجموعات القائمة الجانبية (والمهام بدون تاب تحت «عام»)، وقائمة «لأي تاب» في نافذة المهمة مقسّمة بالمجموعات كذلك.
