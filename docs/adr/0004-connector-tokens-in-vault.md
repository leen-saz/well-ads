# ADR-0004: توكنات المنصات في Supabase Vault، وأسرار النظام في GitHub/Cloudflare

**الحالة:** مقترح · 2026-10-31

**السياق:** الاستراتيجية تحط الأسرار في GitHub Secrets و Cloudflare secrets. توكنات صفحة الربط تتغير من الواجهة (زر "اربط")، والكتابة في أسرار GitHub من التطبيق تحتاج مفتاح GitHub قوي ومكتبة تشفير.

**القرار:** نوعين: أسرار النظام (Supabase, Cloudflare, Vercel) في GitHub/Cloudflare تحطها لين بنفسها، وتوكنات المنصات في Supabase Vault (مشفّرة، والمفتاح برّا القاعدة)، والسيرفر بس يقراها. هذا نفس فصل OWASP بين أسرار البنية وتوكنات الربط.

**الأثر:** السحب يقرا الخزنة أول ويرجع لأسرار GitHub. ما فيه مفتاح GitHub في التطبيق.
