# ADR-0003: سحب البيانات بايثون + PyAirbyte في GitHub Actions (مو Cron Triggers)

**الحالة:** مقترح · 2026-10-31

**السياق:** السحب بايثون (Meta, Google, Snap, GA4) ويحتاج مكتبات وملفات ووقت تشغيل دقايق. كل منصة جديدة كانت تحتاج سحب مكتوب يدوي.

**القرار:** السحب يبقى في GitHub Actions كل ساعة، وPyAirbyte (مترجمات Airbyte المفتوحة بدون سيرفر) للمنصات الجديدة. الناتج يرتفع لـ R2. Cron Triggers في Cloudflare للمهام الخفيفة بس.

**الأثر:** قالب الـ CI في `eng-policies` يحتاج job بايثون. كل منصة جديدة = طبقة تحويل صغيرة لصيغة `rows` بدل سحب كامل.
