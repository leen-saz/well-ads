# ADR-0005: حماية `main` والموافقة على production

**الحالة:** معتمد · 2026-10-31 · قرار لين: نبقى على الخطة المجانية.

**السياق:** الاستراتيجية تشترط حماية `main` (PR + CI إلزامي) ومراجِع إلزامي على بيئة production. خطة GitHub المجانية ما توفرها للريبو الـ private (رد الـ API: "Upgrade to GitHub Pro").

**القرار:** الخطة المجانية.
- لين الوحيدة اللي عندها صلاحية كتابة على الريبو.
- بيئة `production` مقفلة على فرع `main`، والنشر يدوي ويشتغل بس بعد ما ينجح `ci / gate` في نفس التشغيل.
- كلود ينشر على staging بنفسه، ويسأل لين بسطر واحد قبل كل نشر على production.

**الأثر:** أضعف من الحماية الكاملة: الدفع المباشر على `main` ممكن، والـ CI مو إلزامي على الـ PR. نرجع للقرار إذا انضاف شخص ثاني بصلاحية كتابة. قبل أي اشتراك، نتأكد من وثائق GitHub الحالية أي خطة تفتح "required reviewers" للريبو الخاص.

**الخيارات اللي ما اخترناها:** GitHub Pro (~$4 بالشهر)، وريبو public.
