# ربط الليد والبيع بإعلانه: المطلوب من نظام العملاء (لكريم)

الهدف: كل ليد وكل دفعة توصل ومعها ما يربطها بإعلانها، عشان اللوحة تحسب «تكلفة العميل الدافع» لكل حملة بدون تخمين.
اللوحة اليوم (`pipeline/crm/join.py`) تربط بهالترتيب، وما تخمّن غيره: رقم الإعلان `ad_id` ← اسم الإعلان إذا ما فيه إلا إعلان واحد بهالاسم ← آخر إعلان جاب نفس العميل (`customer_id`) خلال 90 يوم. اللي ما ينربط يظهر «غير مربوط» وما ينحسب لأي حملة.

## لكل ليد (الجدول `crm_leads`)

| الحقل | المطلوب | ملاحظة |
|---|---|---|
| `lead_id` | نص ثابت وفريد | |
| `customer_id` | نفس العميل = نفس الرقم دايماً | يربط الدفعة اللي تنسجل على ليد جديد (يدوي/واتساب) بالإعلان الأول |
| `source_platform` | أحد: `meta_form`، `meta_ctwa`، `whatsapp_ad_prefill`، `snapchat_form`، `tiktok_form`، أو مصدر غير إعلاني (`manual`، `referral`…) | لا نكتب «instagram» أو «facebook» بدون تحديد |
| `ad_id` | رقم الإعلان من المنصة كنص كامل، بدون تحويل لصيغة علمية (`1.87E+15` ممنوع) | أهم حقل. من الفورم: `ad_id` اللي ترسله ميتا/سناب/تيك توك. من واتساب: `ref`/`ctwa_clid` يتحوّل لرقم الإعلان |
| `ad_id_quality` | `ok`، أو `broken_by_import` إذا الرقم تضرر | |
| `campaign_id` و`adset_id` | رقم الحملة والمجموعة | احتياطي إذا الإعلان انحذف، نربط على الأقل بالحملة |
| `ad_name` | اسم الإعلان كما في المنصة بالضبط | احتياطي فقط |
| `click_id` | `fbclid` / `ctwa_clid` / `ttclid` / `ScCid` حسب المنصة | يثبت الربط إذا ضاع الرقم |
| `utm_source`، `utm_campaign`، `utm_content` | من رابط الإعلان | `utm_content` = رقم الإعلان لو أمكن |
| `created_at` | وقت وصول الليد (UTC) | |
| `platform_created_at` | وقت تعبئة النموذج في المنصة (للاستيراد المتأخر) | |

## لكل بيع / دفعة

| الحقل | المطلوب |
|---|---|
| `lead_id` و`customer_id` | الليد اللي صار منه البيع (مو ليد جديد منفصل) |
| `payment_status` | `paid` فقط للمدفوع فعلاً (`unpaid`، `refunded`… لغير ذلك) |
| `amount_paid_sar` | المبلغ المدفوع بالريال، أكبر من صفر |
| `paid_at` | وقت الدفع (UTC) |
| `ad_id` / `campaign_id` | يُنسخ من الليد الأصلي تلقائياً، حتى لو الدفع انسجل على سجل ثاني |
| `source_platform` | مصدر الليد الأصلي، مو مصدر تسجيل الدفعة |

## قواعد
- نص كامل لكل الأرقام (لا Excel، لا CSV بدون نص).
- ما نغيّر الرقم بعد الوصول؛ التصحيح يجي بسجل جديد بنفس `lead_id`.
- بدون `ad_id` ولا `campaign_id` ولا `customer_id` مربوط، البيع يظل «غير مربوط» في اللوحة.

## جهة اللوحة (بعد ما توصل الحقول)
`join.py` يقرأ اليوم `ad_id` و`ad_name` و`customer_id`. لما تتأكد أسماء `campaign_id` و`click_id` و`utm_*` في الجدول، نضيف الربط بالحملة (بدون ربط بإعلان محدد) كخطوة منفصلة وبتأكيد من الأعداد (`crm.attribution`) قبل ما نعتمد عليه.
