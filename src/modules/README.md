# الموديولات

كل تاب في نظام الإيجنتس موديول مستقل. المطوّر يشتغل على موديوله بس، بدون ما يلمس الباقي.

## ملفات الموديول
| المكان | وش فيه |
|---|---|
| `src/modules/<key>/module.ts` | الاسم بالعربي والإنجليزي، الأيقونة، الوجهة في القائمة (`group`: home / produce / distribute / measure / optimize / system، بترتيب القائمة)، الحالة (`live` / `soon`)، ووش يسوي |
| `src/modules/<key>/routes.ts` | الـ API: `/api/<key>/<action>` |
| `src/modules/<key>/*.ts` | منطق الموديول |
| `src/modules/<key>/Page.astro` | الصفحة (`/<key>/`)، و`src/pages/<key>/index.astro` سطرين يستوردها بس |
| `public/modules/<key>/client.js` | سكربت الصفحة (`export default async function mount()`) |
| `src/modules/<key>/<key>.test.ts` | التستات |
| `supabase/migrations/NNN_<key>.sql` | جداول الموديول، وكل جدول فيه `company_id` |

## موديول يظهر داخل تاب ثاني
`into: '<key>'` في `module.ts` يخلي الموديول قسماً داخل تاب ثاني بدل مدخل في القائمة (الفويس أوفر داخل الصوت، والكوبي رايتر داخل المحتوى). الرابط `/<into>/?tab=<key>`، والصلاحية والقفل وAPI تبقى للموديول نفسه، والرابط القديم `/<key>/` يحوّل للقسم.

## موديول جديد
1. مجلد `src/modules/<key>/` فيه `module.ts` بحالة `soon`، وسطر في `src/modules/registry.ts`.
2. لما يجهز: `status: 'live'`، و`routes.ts`، وسطر في `src/modules/routes.ts`، والصفحة والسكربت.
3. الصلاحيات والقائمة الجانبية والقفل لكل شركة تشتغل لحالها من السجل.

## القواعد
- كل استعلام يمر على `scoped()` (`src/lib/tenant.ts`): بيانات كل شركة معزولة.
- القراءة `requireUser(request, e, '<key>')`، والكتابة `{ write: true }`.
- الشركة تقدر تقفل أي موديول من الإعدادات ← الموديولات، والمقفل يرجع 403 حتى للمالكة.
- أي تنفيذ حساس له وضعين: بموافقتي أو تنفيذ تلقائي (مع تنبيه).

## الملاحة (القائمة الجانبية والتابات)

- ست مجموعات بالترتيب: الرئيسية، الإنتاج، النشر، القياس، القرارات، النظام (`GROUPS` في `public/assets/sidebar.js`). مفاتيح المجموعات ما تغيّرت (`optimize` اسمها القرارات).
- الإنتاج أربع مداخل: نص (المحتوى و SEO + الكوبي رايتر)، تصميم (+ وصف الصور)، صوت وفيديو (الصوت + الفويس أوفر + التفريغ + الفيديو)، المكتبة. القسم داخل التاب يتحدد بـ `into` في `module.ts`، وصفحة التاب تبدّل القسم من `?tab=` (`src/pages/<تاب>/index.astro`)، والعنوان القديم `/<قسم>/` يحوّل للمكان الجديد من البوابة (`src/lib/gate.ts`).
- القياس يبقى كما هو: ملخص الأداء والمواد الإعلانية والرصد مداخل منفصلة بعناوينها الحالية (ما تغيّروا).
- اللي ما يفتح للمستخدم ما يظهر في القائمة. واللي مقفل لشركته أو لسا ما جهز ينطوي في صف واحد «أقسام قادمة» يفتح صفحة تشرح السبب. البوابة تمنع الصفحات نفسها بغض النظر عن القائمة.
