# وصف الصور (`vision`)

الحالة: **جاهز، ومقفل لكل شركة لين تفتحه المالكة** (الإعدادات ← الموديولات)

- ارفع صورة إعلان (حقنا أو حق منافس) ويطلع وصفها بالعربي ونص بديل جاهز
- النص اللي داخل الصورة بحروفه، والعرض والهوك والدعوة
- ملاحظات الامتثال بنفس قواعد باقي النظام (`check` مع كلمات الشركة الممنوعة)، وتنبيه لو فيه أشخاص
- الصورة تنصغّر وتنعاد ترميزها في المتصفح (وهذا يشيل بيانات موقعها) وما تنحفظ؛ نفس الصورة داخل الشركة ما تنحلل مرتين (بصمتها). الناتج ينحفظ في المكتبة بزر
- Gemini عن طريق `src/lib/llm.ts`، والتكلفة في `ai_usage` وتحت سقف التاب الشهري. المفتاح: `GEMINI_API_KEY`

**الملفات:** module.ts، routes.ts، vision.ts (القواعد والبرومبت)، Page.astro، `public/modules/vision/client.js`، vision.test.ts، والتفاصيل في docs/vision.md
