# المعرفة (`knowledge`)

الحالة: **شغال**

- اللي يتعلمه الذكاء الاصطناعي عن الشركة: صوت العلامة، الخدمات والأسعار، الادعاءات المعتمدة، الممنوع، إعلانات نجحت، مراجع أسلوب (كتّاب ومنافسين نقلّد أسلوبهم بس، مو ادعاءاتهم)، ملاحظات.
- **شات التدريب** (`training.ts`): الإيجنت يسأل 12 سؤال أساسي واحد واحد (الخدمات، الأسعار، العميل، المناطق، الحجز، ليش نحن، الادعاءات، العروض، النبرة، الممنوع، مراجع الأسلوب، إعلان نجح). بعدها الذكاء الاصطناعي يقرا المعرفة ويسأل عن أهم شي ناقص لين يقول اكتملت. كل جواب ينحفظ بند معرفة (`source = training`) يتعدل من «كل المعرفة».
- كل بند يطبّق على كل الموديولات أو على موديولات محددة.
- الإضافة والتعديل بصلاحية تعديل. التفعيل والإيقاف بصلاحية موافقة، واللي يضيفه أو يعدّله أحد بدون موافقة يبقى موقوف لين يعتمده المدير.
- ما فيه حذف: الإيقاف يكفي ويبقى السجل.
- **الهوية والبصريات** (`brand.ts`، جدول `brand_assets` في migration 016): الشعار، ألوان العلامة (hex)، الخطوط، دليل العلامة (PDF)، وصور مرجعية.
  - الملفات في R2 تحت `brand/<company>/`، وما تنفتح إلا من السيرفر للشركة نفسها (`/api/knowledge/brandfile`، والتصميم يشوف الفعّال بس من `/api/design/brandfile`).
  - الصيغ والأحجام محددة لكل نوع: الشعار PNG/JPG/WebP/SVG بحد 2 ميقا، والخط WOFF2/WOFF/TTF/OTF بحد 5، والدليل PDF بحد 20، والصور المرجعية بحد 5. الصور تتصغّر في المتصفح قبل الرفع.
  - الصورة المرجعية تنوصف مرة وحدة وقت الرفع (Workers AI)، والتصميم يستخدم الوصف.
  - نفس قاعدة البنود: اللي يرفعه أحد بدون صلاحية موافقة يبقى موقوف، وما فيه حذف.
  - التصميم يستخدم الفعّال تلقائياً: الشعار مكان «Well.»، وألوان العلامة للتدرّج والزر، والخط، ووصف الصور المرجعية في النص.
- «وش يوصل للذكاء الاصطناعي» يعرض نص رسالة الـ system بالضبط لكل موديول.

## للموديولات
```ts
import { knowledgeFor, withKnowledge } from '../knowledge/knowledge';
const messages = withKnowledge([{ role: 'user', content: prompt }], await knowledgeFor(cfg, user.co, '<key>'));
```
المعرفة تروح رسالة `system` مستقلة، وما تنخلط مع نص المستخدم. لو الجدول ما انقرا (مثلاً migration 014 ما طُبّق)، الموديول يكمل بدونها.

الجدول: `supabase/migrations/014_knowledge.sql`.
