# الامتثال (`compliance`)

الحالة: **شغال**

- يفحص نصوص الإعلانات المحفوظة (`ads.doc.text`) على قواعد الإعلان الصحي في السعودية وسياسات ميتا وتيك توك وسناب.
- لكل مخالفة: الكلمة، السبب، والصياغة الأسلم. النص المكرر على أكثر من إعلان ينعرض مرة وحدة.
- فاحص نص حر قبل النشر (`POST /api/compliance/check`).
- تنويه بس، ما يمنع النشر، وما يغيّر شي في حسابات الإعلانات.

القواعد في `compliance.ts` (`RULES`): كل قاعدة نمط ومستوى وسبب وحل. أضف قاعدة بسطر. ما يحتاج جداول جديدة.
