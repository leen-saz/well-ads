# التفريغ (`transcribe`)

الحالة: **جاهز، ومقفل لكل شركة لين تفتحه المالكة** (الإعدادات ← الموديولات)

- ارفع صوت أو فيديو (اجتماع، إعلان منافس، مقطع تيك توك) ويطلع نص باللهجة مع التوقيت
- ملخص وبنود عمل للاجتماعات، والهوك في أول 3 ثواني والعرض للإعلانات
- الملفات الطويلة تنفرّغ على خطوات (10 دقايق كل خطوة): الصفحة تكمل الخطوات، وإذا انقفلت يكملها الكرون كل 5 دقايق
- الملف ينحذف من R2 ومن Google بعد التفريغ، ويبقى النص. النتيجة تنحفظ في المكتبة كمسودة
- Gemini عن طريق `src/lib/llm.ts`، والتكلفة في `ai_usage` وتحت سقف التاب الشهري. المفتاح: `GEMINI_API_KEY`

**الملفات:** module.ts، routes.ts، transcribe.ts (القواعد والبرومبتات)، service.ts (خطوة وحدة + الكرون)، Page.astro، `public/modules/transcribe/client.js`، transcribe.test.ts، والتفاصيل في docs/transcribe.md
