# الفويس أوفر (`voiceover`)

الحالة: **جاهز، ومقفل لكل شركة لين تفتحه المالكة** (الإعدادات ← الموديولات)

- اكتب النص ويتحول لصوت عربي بلهجة سعودية (نجدية، حجازية، جنوبية) أو خليجية أو فصحى، وتسمعه قبل ما تنزّله WAV
- الصوت واللهجة والنبرة والإيقاع، وتحفظها كصوت للعلامة (`voiceover_settings`) تنطبق على كل توليد
- فحص الامتثال للنص (تنبيه بس)، وحفظ النص في المكتبة (`kind = script`)
- Gemini عن طريق `src/lib/llm.ts`، والتكلفة في `ai_usage` وتحت سقف التاب الشهري. المفتاح: `GEMINI_API_KEY`. الصوت ما ينحفظ

**الملفات:** module.ts، routes.ts، voiceover.ts (الخيارات والبرومبت وقراءة التكلفة)، Page.astro، `public/modules/voiceover/client.js`، voiceover.test.ts، والتفاصيل في docs/voiceover.md
