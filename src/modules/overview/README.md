# نظرة عامة (`overview`)

أول تاب مبني على **shadcn/ui** (React + Tailwind)، من قالب [dashboard-01](https://ui.shadcn.com/blocks#dashboard-01) بعد تنظيفه وتشغيله على بياناتنا.

| الملف | وش فيه |
|---|---|
| `numbers.ts` | الحساب كله من `/dash.json` بنفس قواعد اللوحة الرئيسية: الفترة تنتهي بآخر يوم كامل (`range.end`)، والنتائج = الليدز + المحادثات، والمقارنة بس لما الفترة اللي قبل كاملة وما فيه منصة ناقصة. `audience_network` و`meta_whatsapp` تنحسب في المجاميع وما تنعرض في الجدول |
| `Overview.tsx` | يجيب البيانات ويختار الفترة (7 / 30 / 90 يوم) |
| `SectionCards.tsx` | كروت الصرف والنتائج وتكلفة النتيجة ونسبة النقر، مع نسبة التغيّر |
| `TrendChart.tsx` | الرسم اليومي (Recharts) |
| `analytics.ts` | باقي صفحة التحليلات بنفس قواعدها: حصة كل منصة من الصرف والنتايج، وتيرة الشهر وتوقعه (أيام كاملة بس، وبعد 3 أيام، وبدون توقع لو منصة ناقصة)، تكلفة الليد حسب يوم الأسبوع (إعلانات الليدز)، والأقسام |
| `OutcomeCards.tsx` | النتيجة (الإقفالات والمدفوع والعائد وتكلفة العميل)، وكرت رحلة العميل: فلتر المنصة، الحكم جنب الرسم، سطر «التحليل» لكل خطوة، والأرقام كجدول |
| `funnel.ts` | تحليل الرحلة بالقواعد (بدون نموذج وما تطلع الأرقام لأي مكان): كل خطوة مقارنة بالفترة اللي قبلها (لو المقارنة صحيحة) وبالوسيط اليومي لآخر 30 يوم وبحد أدنى (`FLOORS`). أضعف خطوة عنق الزجاجة، ونقص ربط نظام العملاء يجي قبل كل شي. وفيه شكل الشريط: الارتفاع لوغاريتمي من الحجم، والوصلة تضيق مع ضعف الخطوة |
| `FunnelChart.tsx` | الشريط نفسه (d3-shape للمنحنى، و`animateValue` من motion للحركة، ويحترم `prefers-reduced-motion`). يتحمّل متأخر بعد الأرقام. المرحلة الأولى يمين والرحلة تمشي لليسار، ويتمرر داخل كرته على الجوال |
| `AnalyticsCards.tsx` | كروتها: حصة المنصات، وتيرة الشهر، الأقسام (تفتح صفحة القسم)، والخريطة الحرارية |
| `AdsTable.tsx` | جدول الإعلانات (TanStack Table): ترتيب، بحث، فلتر منصة، أعمدة، صفحات، ولوحة جانبية لكل إعلان |
| `creatives.ts` | تاب «الكرييتف بالتفصيل» (`/overview/creative/`): كل فكرة (`ideaKey`) بنسخها وإعلاناتها، والفلاتر (منصة، قسم، هدف، صيغة)، وتكلفة الليد من إعلانات الليدز بس (`leadSpend / leadN`) مثل `pipeline/dash/10-creative.js`، ونسبة اللي وقفوا يشوفون مدى الحياة. المعاينة بس من نفس الموقع أو `data:` (CSP)، والباقي يفتح في تاب جديد |
| `Creative.tsx` | صفحتها: كروت الأفكار، ولوحة جانبية فيها النسخ جنب بعض (الأفضل ملوّن) والإعلانات المربوطة |
| `PerfTabs.astro` | تابات الأداء فوق الصفحتين: نظرة عامة، والكرييتف بالتفصيل. وفي القائمة الجانبية تطلع تحت نظرة عامة من `pages` في `module.ts` |
| `useDash.ts` | جلب `/api/overview/data`، مشترك بين الصفحتين |
| `src/components/ui/*` | مكوّنات shadcn المشتركة، بكلاسات منطقية (`ms-`/`pe-`/`start-`) عشان العربي |
| `src/styles/ui.css` | ألوان وِل على متغيرات shadcn (`--ui-*`)، ويتحمّل في صفحات shadcn بس |

## اللي انشال من القالب
البيانات الوهمية، والقائمة الجانبية والهيدر (عندنا قائمتنا)، وسحب الصفوف (dnd-kit)، وتحديد الصفوف، و`zod`، و`next-themes`، و`sonner`، و`vaul`، وأيقونات Tabler (نستخدم Lucide مثل باقي الموقع).

## إضافة مكوّن shadcn
`npx shadcn@latest add <name>` (الإعداد في `components.json`، و`rtl: true`)، وبعدها تأكد إن الكلاسات منطقية.
