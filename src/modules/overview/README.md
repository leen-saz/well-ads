# نظرة عامة (`overview`)

أول تاب مبني على **shadcn/ui** (React + Tailwind)، من قالب [dashboard-01](https://ui.shadcn.com/blocks#dashboard-01) بعد تنظيفه وتشغيله على بياناتنا.

| الملف | وش فيه |
|---|---|
| `numbers.ts` | الحساب كله من `/dash.json` بنفس قواعد اللوحة الرئيسية: الفترة تنتهي بآخر يوم كامل (`range.end`)، والنتائج = الليدز + المحادثات، والمقارنة بس لما الفترة اللي قبل كاملة وما فيه منصة ناقصة. `audience_network` و`meta_whatsapp` تنحسب في المجاميع وما تنعرض في الجدول |
| `Overview.tsx` | يجيب البيانات ويختار الفترة (7 / 30 / 90 يوم) |
| `SectionCards.tsx` | كروت الصرف والنتائج وتكلفة النتيجة ونسبة النقر، مع نسبة التغيّر |
| `TrendChart.tsx` | الرسم اليومي (Recharts) |
| `AdsTable.tsx` | جدول الإعلانات (TanStack Table): ترتيب، بحث، فلتر منصة، أعمدة، صفحات، ولوحة جانبية لكل إعلان |
| `src/components/ui/*` | مكوّنات shadcn المشتركة، بكلاسات منطقية (`ms-`/`pe-`/`start-`) عشان العربي |
| `src/styles/ui.css` | ألوان وِل على متغيرات shadcn (`--ui-*`)، ويتحمّل في صفحات shadcn بس |

## اللي انشال من القالب
البيانات الوهمية، والقائمة الجانبية والهيدر (عندنا قائمتنا)، وسحب الصفوف (dnd-kit)، وتحديد الصفوف، و`zod`، و`next-themes`، و`sonner`، و`vaul`، وأيقونات Tabler (نستخدم Lucide مثل باقي الموقع).

## إضافة مكوّن shadcn
`npx shadcn@latest add <name>` (الإعداد في `components.json`، و`rtl: true`)، وبعدها تأكد إن الكلاسات منطقية.
