# الرصد (`listening`)

الحالة: **شغال**

- يحلل منشوراتنا العضوية (فيسبوك، انستقرام، تيك توك): المواضيع اللي تتفاعل معها الناس أكثر من المعتاد، المنشورات المميزة، والمنشورات اللي فيها نقاش.
- كلمات تتابعها (تنحفظ في المتصفح): عدد المنشورات، متوسط التفاعل، ومقارنة بالمعتاد.
- الطلب: ليدز كل مصدر هالأسبوع مقابل اللي قبله من `crm_leads`، وتنبيه لو التغيّر ٣٠٪ أو أكثر.

التحليل يشتغل في المتصفح (`public/modules/listening/analyze.js`) من بيانات اللوحة نفسها، لأن خطة Cloudflare المجانية تعطي ١٠ ملي ثانية معالجة بس لكل طلب.
السيرفر: `GET /api/listening/demand` بس. ما يحتاج جداول جديدة.

حدود: نصوص التعليقات نفسها مو محفوظة عندنا للحين (العدد بس). الخطوة الجاية: تعليقات تيك توك عن طريق MCP (`comment_list_get`) وتعليقات ميتا من ربط الصفحات.
