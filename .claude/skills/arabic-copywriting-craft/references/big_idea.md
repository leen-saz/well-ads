## ٢. سلّم الفائدة

```text
المنتج:
الميزة:
الوظيفية:
العاطفية:
الاجتماعية:
```

**مثال:**

| المستوى | المثال |
| :--- | :--- |
| المنتج | تطبيق ميزانية |
| الميزة | تصنيف تلقائي |
| وظيفية | تعرف أين يذهب مالك |
| عاطفية | تنام بلا قلق |
| اجتماعية | تبدو منظماً |

## ٣. الفكرة

> «يجب أن تقدم الفكرة الإعلانية للمستهلك شيئاً ملموساً وبمزايا معينة» (الزعبي، ص ١٠٩).

### ٣.١ اختبارات

1. هل تقول شيئاً واحداً؟
2. هل تخص العميل؟
3. هل تختلف؟
4. هل تُثبت؟
5. هل تُتذكر؟

### ٣.٢ مصادر

| المصدر | السؤال |
| :--- | :--- |
| الاعتراض | لماذا لا يشترون؟ |
| اللحظة | متى يحتاجون؟ |
| المفارقة | ما المتوقع/الواقع؟ |
| الإنسان | من يستفيد؟ |
| الثقافة | ما الرمز؟ |

---

## ٤. المفهوم

> «بدون فكرة أو اقتراح ملائم، سوف تكون الحملة فارغة» (فاربي، ص ١٠٥).

**المفهوم** ترجمة الفكرة: صورة، شخصية، قصة، مقارنة، رمز.

| المفهوم | المثال |
| :--- | :--- |
| صورة | نمر = قوة |
| شخصية | «الخط المباشر» |
| قصة | «قبل/بعد» |
| مقارنة | «نحن/هم» |
| رمز | «المفتاح» |

**تحذير:** المفهوم ليس زخرفة. إن لم يحمل الفكرة، فهو ضوضاء.

---

## ٥. الوعد

> «إذا لم يكن لدى المنتج ما يعد به العميل، ليس هناك ما يدعو إلى أخذه في الحسبان» (فاربي، ص ١٠٧).

**قالب:** «[المنتج] يمنحك [الفائدة] دون [العائق].»

**اختبار:** هل يمكن الوفاء به؟ إن لا، فخفّضه.

## ٦. الدليل

| النوع | المثال |
| :--- | :--- |
| رقم | «٩ من ١٠» |
| شهادة | «جرّبته سنة» |
| ضمان | «استرداد ٣٠ يوماً» |
| تجربة | «قبل/بعد» |
| مصدر | «مختبر مستقل» |

> «اعتن في رسالتك بتقديم البراهين والأدلة» (الزعبي، ص ١٦٩).

## ٧. الفكرة والعنوان

- الفكرة ما تقوله.
- العنوان أول ما يُقرأ.
- الاثنان يجب أن يتطابقا.

**اختبار:** هل يستطيع العنوان وحده حمل الفكرة؟ إن لا، فأعد.
