## ١. الموجز

```text
العلامة:
المنتج:
المشكلة:
الجمهور:
الفكرة:
الوعد:
الدليل:
الاعتراضات:
النبرة:
إلزامي:
ممنوع:

```

**قاعدة:** صفحة واحدة. إن احتاج أكثر، فالفكرة غير واضحة.

## ٢. الوسائط

| الوسيط | القوة | الخطر |
| :--- | :--- | :--- |
| صحافة | تفصيل | تراجع |
| تلفزيون | صورة/صوت | تكلفة |
| إذاعة | تكرار | لا صورة |
| خارجي | محلي | رسالة قصيرة |
| سوشيال | استهداف | تشتت |
| بحث | نية | منافسة |
| بريد | علاقة | spam |

> «اختيار الوسيلة الإعلانية… العامل الحقيقي لنجاح الإعلان» (الزعبي، ص ١٠٩).

### ٢.١ اختيار الوسيط

1. أين الجمهور؟
2. كم مرة يحتاج أن يرى؟
3. ما الميزانية؟
4. ما شكل الرسالة؟
5. ما القياس؟

**قاعدة:** لا تختار الوسيط لأنك تحبه؛ اختره لأن الجمهور فيه.

---

## ٣. الميزانية

| الطريقة | الأساس |
| :--- | :--- |
| نسبة من المبيعات | استقرار |
| هدف النمو | طموح |
| حصة المنافس | سوق |
| تكلفة الوصول | كفاءة |

**قاعدة:** لا ميزانية قبل هدف قابل للقياس.

---

## ٤. القياس

| المقياس | السؤال |
| :--- | :--- |
| الوصول | كم رأى؟ |
| التذكر | ماذا تذكر؟ |
| الفهم | هل فهم؟ |
| النية | هل يريد؟ |
| الفعل | كم اشترى؟ |
| التكلفة | كم كلفة التحويل؟ |

> «توصيل الرسالة الإعلانية المناسبة في الوقت المناسب للجمهور المناسب» (الزعبي، ص ١٨٥).

### ٤.١ الاختبار

- نسختان (A/B).
- جمهور متشابه.
- متغير واحد.
- مدة كافية.
- قرار مبني على النتيجة.

---

## ٥. الأخلاق

### ٥.١ الصدق

- لا ادعاء بلا دليل.
- لا «الأفضل» بلا معيار.
- لا «مجاني» بشروط مخفية.
- لا شهادة مخترعة.
- لا صورة مضللة.

### ٥.٢ ما لا يُفعل

| المحظور | لماذا |
| :--- | :--- |
| الخوف | استغلال |
| التمييز | كرامة |
| استغلال الأطفال | حماية |
| التضليل | ثقة |
| الإلحاح الكاذب | احترام |
| الادعاء الصحي | قانون |
| الشروط المخفية | عدالة |

### ٥.٣ الإفصاح

- «إعلان».
- «محتوى مدفوع».
- «بالتعاون مع».
- «رابط تابع».

**قاعدة:** إن كان القارئ سيغضب إن عرف الحقيقة، فلا تنشر.
