## ١. AIDA

> «الانتباه والاهتمام والرغبة والإقناع والاستجابة والذاكرة» (الزعبي، ص ١٥٩).

```text
Attention:  أوقف التمرير.
Interest:   لماذا يهمني؟
Desire:     كيف تتحسن حياتي؟
Conviction: لماذا أصدقك؟
Action:     ماذا الآن؟
Memory:     ماذا أتذكر؟
```

## ٢. العنوان

> «ما بين ٥٠٪ إلى ٩٠٪ من نجاح الرسالة… يرجع إلى تكوين العنوان الرئيسي» (الزعبي، ص ١٧٢).

### ٢.١ الوظائف

- يعبر عن الكثير بكلمات قليلة.
- يجذب بالمغري.
- يدفع للقراءة.
- لا تُرى فيه الصنعة.

### ٢.٢ الصيغ

| الصيغة | المثال |
| :--- | :--- |
| فائدة | «وفّر ساعتين» |
| سؤال | «لماذا تستيقظ متعباً؟» |
| رقم | «٣ خطوات» |
| مفارقة | «أغلى… أرخص» |
| أمر | «لا تشترِ…» |
| شهادة | «جرّبته…» |
| فضول | «الخطأ الذي…» |

### ٢.٣ قبل/بعد

| قبل | بعد |
| :--- | :--- |
| «الحل الأمثل» | «فاتورتك أقل ٢٠٪» |
| «نحن الأفضل» | «٣ مزودين… سعر واحد» |
| «اتصل الآن» | «احسب توفيرك» |

---

## ٣. النص

```text
① عنوان
② مشكلة/رغبة
③ فائدة
④ دليل
⑤ اعتراض
⑥ CTA
```

**قواعد:** جملة قصيرة، فقرة قصيرة، «أنت»، فعل معلوم، لا حشو.

---

## ٤. CTA

| النوع | المثال |
| :--- | :--- |
| مباشر | «اشترِ الآن» |
| ناعم | «اعرف المزيد» |
| تجريبي | «جرّب مجاناً» |
| محدود | «احجز قبل الخميس» |
| تفاعلي | «احسب» |

**قاعدة:** CTA واحد. وإن كان هناك فعلان، فأحدهما ليس ضرورياً.

---

## ٥. الشعار

- ٢–٥ كلمات.
- سهل النطق.
- فكرة.
- يصمد بلا صورة.

**أمثلة:** «فكّر أبعد»، «معك خطوة بخطوة»، «طعم البيت».

---

## ٦. الوسائط

| الوسيط | الطول | البداية |
| :--- | :--- | :--- |
| سوشيال | ١–٣ أسطر | خطاف |
| بحث | ٢–٤ أسطر | فائدة |
| بريد | ٥٠–١٥٠ كلمة | موضوع |
| صفحة | ٣٠٠–٨٠٠ | عنوان |
| وصف | ٦٠–١٥٠ | فائدة |

---

## ٧. صفحة الهبوط

