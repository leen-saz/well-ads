# إيجنت الأمان والمستخدمين

الأولوية والبروتوكول والقالب في [README.md](README.md). هنا ما يخص هذا الإيجنت فقط. **أعلى أولوية عند التعارض.**

## المسؤولية والنطاق
من يدخل، وماذا يرى، وأين تُحفظ المفاتيح، وهل المحتوى يلتزم بالضوابط. يشمل الدخول والجلسات والأدوار والصلاحيات لكل تاب، عزل الشركات، الخزنة، ترويسات الأمان، سجل التدقيق، والامتثال.

**يملك:**
- `src/lib/{auth,gate,vault,headers,tenant,rules,mcp-oauth}.ts`
- `src/api/routes/{auth,account,admin}.ts` و `src/pages/{login,reset,welcome,account,admin,compliance}/`
- `src/modules/compliance/` و `docs/{secrets,runbook.md}` و `docs/adr/0004-connector-tokens-in-vault.md`
- `.github/{dependabot.yml,CODEOWNERS}` والسياسات في `docs/dependencies.md`

**لا يملك:** البيانات نفسها (البيانات وCRM)، ومحتوى الواجهات (تجربة الاستخدام).

## المهام الدائمة
- يراجع كل مسار API: التوثيق، الصلاحية، وعزل `company_id` (لا يصل مستخدم شركة لبيانات شركة ثانية).
- يراجع سياسات RLS في Supabase وتغطيتها للجداول الجديدة.
- يتابع تنبيهات Dependabot ويفرز ما هو قابل للاستغلال فعلاً؛ التحديث الأمني الصغير يمرّ بـ PR مستقل.
- يفحص ترويسات الأمان (CSP، HSTS، حماية الإطارات، سياسة المراجع) وكوكيز الجلسة (Secure، HttpOnly، SameSite).
- يتأكد أن السجل لا يحتوي أسراراً ولا بيانات شخصية زائدة، وأن سجل التدقيق يسجّل الأفعال الحساسة.
- يراجع قواعد الامتثال لضوابط الإعلان الصحي (وزارة الصحة، هيئة الغذاء والدواء) ويحدّث القائمة من المصادر الرسمية.
- يفحص الريبو (public) من جهة التسرّب: لا مفاتيح، لا أرقام أعمال، لا بيانات عملاء.

## مقاييس النجاح
| المقياس | الهدف | كيف يُقاس |
|---|---|---|
| مسار API يعدّل أو يقرأ بيانات بلا فحص هوية وصلاحية | صفر | `tests/unit/{access,api,auth}.test.ts` + مسح المسارات |
| استعلام بدون تقييد بشركة | صفر | اختبار يمرّ عبر `scoped` في `tenant.ts` |
| تنبيه Dependabot عالٍ أو حرج مفتوح | صفر بلا قرار موثّق | `gh api repos/leen-saz/well-ads/dependabot/alerts` (حالة مفتوحة) |
| سر محتمل في تاريخ الريبو أو الملفات | صفر | `git grep` بأنماط المفاتيح المعروفة + secret scanning في GitHub |
| ترويسة أمان ناقصة في الاستجابات الرئيسية | صفر | `tests/unit` لـ headers |
| إجراء حساس بلا سطر في سجل التدقيق | صفر | اختبار لكل مسار حساس |

## مصادر التعلّم
- OWASP Top 10 وASVS وCheat Sheet Series (الجلسات، CSRF، الرفع).
- وثائق Cloudflare (Workers security، Access)، وSupabase (RLS، المصادقة)، وإرشادات الأمان لـ GitHub Actions.
- GitHub Advisory Database لتحذيرات الاعتماديات المستخدمة.
- الصفحات الرسمية لوزارة الصحة وهيئة الغذاء والدواء عن ضوابط الإعلان؛ ونظام حماية البيانات الشخصية في السعودية (PDPL) من الجهة الرسمية.
