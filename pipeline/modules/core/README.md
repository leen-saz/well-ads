# core

المشترك الوحيد بين الموديولات. أي موديول يقدر يستورد منه، وما يستورد من داخل موديول ثاني.

- `__init__.py`: المنصات، وتحويل مفتاح الإعلان لمنصته، ومفاتيح التشغيل من `config/modules.json`، وقراءة `data.json`.
- `rules.py`: قواعد لين الثابتة، و`check(suggestion, today)` اللي يرجع المخالفات. ما تتغيّر إلا بـ PR توافق عليه لين.
- `supa.py`: عميل Supabase بمفتاح السيرفر (`SUPABASE_URL`، `SUPABASE_SERVICE_ROLE_KEY`). يرجع `None` بدون مفاتيح.
