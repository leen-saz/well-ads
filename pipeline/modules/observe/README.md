# observe

يراقب حركات الميديا باير **داخل المنصات** (مو بس في اللوحة)، قراءة فقط.

- **يقرا:** سجل نشاط Meta (`act_<id>/activities`)، و`change_event` في Google، آخر 3 أيام.
- **يكتب:** `platform_activity` (التكرار ينتجاهل).
- **ما يغطي:** Snap وTikTok، لأنهم ما يعطون سجل نشاط بالـAPI.
- **يستخدمه:** `learn`، ويطلع في تبويب "التعلّم" في لوحة القرارات.
