# critic

مراجع ثاني لكل اقتراح قبل ما يوصل للموافقة.

- **يقرا:** الاقتراحات المفتوحة اللي ما انراجعت (`critic is null`)، وقواعد `modules/core/rules.py`، والدروس `lessons` (المرحلة C).
- **يكتب:** `suggestions.critic = {ok, issues, at}` وسطر في `audit_log`.
- **الأثر:** الاقتراح اللي `ok=false` ينرفض بس في اللوحة، والسبب يطلع جنبه. وبعدين المنفّذ (المرحلة B) يرفض أي تنفيذ ما عدّى المراجع.
